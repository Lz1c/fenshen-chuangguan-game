Overview

The Advanced Turret AI System lets you drop‑in intelligent turrets, tanks, and defense systems without writing a single line of code. Everything – range, line‑of‑sight, predictive aiming, projectile or raycast fire, obstacle checks, gizmos – is handled for you.

Key Features

  • Zero‑code setup via the Turret Creator menu.
  • Projectile or raycast firing modes, with predictive lead‑targeting.
  • 3D audio with single or randomized shot sounds.
  • Visual gizmos for range, fire cone, spawn points, obstacle rays.
  • Extensible events (UnityEvent) for full control.

Quick Start

  1. Install the package into your project.
  2. Create a turret: GameObject ▸ Turret ▸ Create Single/Double Barrel Turret. The prefab is dropped into the scene fully wired up.
  3. Press Play – the turret will seek anything tagged Enemy. Add the included LinearPingPongMover script to a capsule to see it track a moving target.

Required Components

Each turret root needs TurretController and TurretSoundManager. Those are added automatically by the creator, but you can add them manually from Components ▸ Advanced Turret AI.

Turret Workflow

  1. Assign a Projectile Prefab (or leave default for raycast mode).
  2. Optionally drop in a Trail VFX prefab for raycast shots and a Muzzle Decal prefab for muzzle flashes.
  3. Tweak Range, Fire Rate, and Damage in the inspector.
  4. Use the in‑scene gizmos to validate spawn points, detection cone, and obstacle checks.

TurretSoundManager

  • Single Shot Sound – one clip played every shot.
  • Use Random Sounds – toggle to pick a random clip from Random Shot Sounds each fire.
  • Spatial Blend / Max Distance – standard 3D audio controls.

TurretProjectile

  • Mode: Directional (straight) or Homing.
  • Speed / LifeTime – self‑destruct after LifeTime.
  • Collision Layers – layers that register a hit.
  • UnityEvent enemyHit(GameObject enemy, float damage) provided for custom FX.

Example: Creating a Homing Missile Turret

  1. Duplicate the default projectile prefab, change Mode to Homing, Speed to 30.
  2. Set turret Shoot Mode to Projectile and assign your new missile prefab.
  3. Increase Max Angle Deviation to allow easier firing.

Troubleshooting

  • Turret doesn’t rotate – ensure _targetEnemy exists and enemyTag matches.
  • No bullets spawn – add at least one ProjectileSpawnPoint under the head.
  • Sound is 2D – set Spatial Blend to 1 on TurretSoundManager.
